 # Unix Command Line Workbook

This workbook contains practical exercises for learning Unix commands. Each section focuses on different Unix concepts and provides hands-on exercises to reinforce your learning.

## How to Use This Workbook

1. Navigate through the exercises in sequential order
2. Read the descriptions and instructions in each exercise file
3. Try to solve the exercises on your own before checking the solutions
4. Use the reference sheets for command syntax and examples

## Workbook Structure

- `exercises/` - Contains all the practical exercises
- `data/` - Sample files and directories used in the exercises
- `solutions/` - Contains solutions to the exercises (check only after trying yourself)
- `reference/` - Quick reference guides for Unix commands

## Getting Started

Begin with Exercise 1 in the `exercises/` directory:

```bash
cd exercises
cat 01_navigation_basics.md
```

Happy learning!!
